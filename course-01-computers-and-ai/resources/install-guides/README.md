# Install guides

> **You don't need any of these to start.** This course is browser-and-built-in-apps only until
> Module 6. Come here **only when a module tells you to** — each guide says which module needs it.

| Guide | You'll need it at | What it's for |
|---|---|---|
| [codespaces.md](codespaces.md) | **Modules 3–6** *(if your class uses it)* | A ready-made Linux computer in your browser — nothing to install |
| [terminal.md](terminal.md) | **Module 3** (and M4–M5) | Opening your computer's terminal — no install, just how to find it |
| [docker.md](docker.md) | **Module 6** | Installing Docker (or using a free browser playground instead) |

> **Using a Codespace?** If your class uses the hosted environment ([codespaces.md](codespaces.md))
> for Modules 3–6, everything is pre-installed — you can skip the terminal and Docker setup below.

Modules **7–8** (AI) use free websites your instructor will link in class — nothing to install.

If a guide's steps don't match what you see, that's usually because the tool updated — tell your
instructor, and use the "stuck" steps in [START-HERE](../../START-HERE/README.md) meanwhile.
