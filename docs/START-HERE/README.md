# START HERE 👋 — welcome to *Under the Hood*

You're about to learn how computers and AI **actually** work — not by reading about it, but by
*doing* it. No background needed. If you can use a web browser, you're ready.

## What you need (almost nothing)
- A **laptop** (Mac, Windows, Linux, or a Chromebook).
- A **web browser** (Chrome, Edge, Firefox, or Safari).
- A willingness to click around and break things. (You can't break anything that matters — promise.)

> **You do *not* need to install anything to begin.** Day one needs only your laptop and a
> browser. We add a tool *only* when a lesson needs it, and we walk you through each one when
> the time comes. (Docker arrives at Module 6; everything before that is browser- and
> built-in-app only.)

## How a session works
Every session is **lab-first** — a little framing, then you build something and get a **win in
the first ~20 minutes**. Expect:
- **Breakout pairs** — you'll work alongside a partner and compare screens.
- **A chat wins board** — when you hit your win, you post it. 🎉
- **Errors are normal and safe.** Things going "wrong" is how this works — we'll say so out loud,
  every time. Nobody here is behind.

## How to get help (in this order)
1. Re-read the **✅ You should now see** line under the step you're on.
2. Ask your **breakout partner** — chances are they just hit the same thing.
3. Drop it in the **class chat** — the instructor or a classmate will get you moving in a minute.

## Before your first session — a 2-minute readiness check
- [ ] My laptop turns on and I can reach the internet.
- [ ] I can open a web browser and load a website.
- [ ] I know how to find this course's chat / meeting link.

That's it. **No accounts, no installs yet.** ✅
