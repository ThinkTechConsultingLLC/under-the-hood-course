# Opening your terminal

**Needed from Module 3 onward.** Nothing to install — the terminal is already on your computer.
The terminal is just a window where you type commands (full story in M3's `notes.md`).

## Open it
- **Mac:** press **⌘ + Space**, type **Terminal**, press Enter.
- **Windows:** click **Start**, type **PowerShell**, press Enter. *(Use **PowerShell**, not the older "Command Prompt" — our commands match PowerShell.)*
- **Linux:** open the **Terminal** app (often **Ctrl + Alt + T**).
- **Chromebook:** most class work uses the browser; if you need a Linux terminal, turn on **Settings → Advanced → Developers → Linux development environment**, then open **Terminal**. (Your instructor will confirm whether you need this.)

✅ **You should now see:** a window with some text ending in a **prompt** — a `$` (Mac/Linux) or
`>` (Windows) — and a blinking cursor.

## Check it works
Type this and press Enter:

```text
pwd
```

✅ **You should now see:** the path of the folder you're currently in (e.g. `/Users/yourname`,
`/home/yourname`, or `C:\Users\yourname`). If you see that, your terminal works — you're ready for M3.

> Stuck? You can't harm anything by typing here. If a command "hangs," press **Ctrl-C** to stop it.
